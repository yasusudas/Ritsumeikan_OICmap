## 未完了・次に確認すること

1. **仕様第16章の全12サイズを日英両方で検証する。** 英語側、721px境界、1240px/高さ700px境界は完了していない。PCの広幅カード自体は表示できたが、指定したサイズを全部通過したとは扱わない。
2. ブラウザーのページ拡大率で、viewportに指定した数値と`innerWidth`/`innerHeight`が異なる場合がある。必ず実測CSS寸法を記録する。今回の721px以降の一部試行は130%拡大の影響があったため、有効なサイズ検証として数えない。
3. **狭幅の概要カードの本文高さ。** 320/375pxで長い店名・紹介がある場合も、閉じる・詳しく見るが欠けず、紹介・営業時間の先頭行を内部スクロールで読めるかを実際の描画で確認する。
4. **概要の営業時間表示。** 現在`renderHours()`は先頭サービスだけに絞るが、通常版と臨時版の両方を概要にも生成する。仕様では先頭行/優先版だけなので修正・検証が必要。
5. 短い広幅画面で、一覧をスクロールして店舗を選んだ後、パネル全体のスクロール位置が残って閉じるボタンが画面外にならないか確認する。新店舗選択時の本文スクロールはリセット済みだが、外側パネルの位置も確認が必要。
6. 検索・ハッシュ再読み込み・日英切替・手動階切替・ATM/授乳/プリンター等からの復帰・背景タップ・同一店再選択を実UIで一通り検証する。
7. キーボードのフォーカス/復帰、ホバー200msと退出120ms、スワイプ、実タッチ/ピンチ、200%文字拡大、動きを減らす設定は全面検証していない。ドラッグ8px/2本目/キャンセルは単体テストで検証済み。
8. 元SVGのMini Meal Shopの引き出し線の点・セブン横のATMが派生SVGでも残ることを画像で照合する。幾何に基づく除去と元ファイル不変のテストはあるが、目視照合を仕上げる。
9. PNG仮アイコン合計約6.4MB。正式素材化・軽量化は未実施。生成プロンプトと対応は`public/food-marks/asset-manifest.json`に記録。ブランド規約のURL記録も公開条件に沿って点検する。
10. 第2段階のOICフードページ常設店舗一覧、第3段階の営業状態判定は未着手。今回の第1段階の途中保存に追加しない。

## 再開コマンド・留意事項

```sh
git status --short
git branch --show-current
npm run dev -- --host 127.0.0.1
node --test
npm run check:en
npm run check:search-data
npm run build
```

`pnpm test`は環境の依存関係自動再構築が非TTYで中断し、テスト本体を実行できなかった。同じテストスクリプトを`node --test`で実行した。依存関係を勝手に消して再インストールしない。失敗時にできた`.pnpm-store`は今回作成したファイルだけ除去済み。

ブラウザー操作はCodexのCUAで行った。開発サーバー再起動中に古いタブが接続エラーになった場合は、サーバー応答を確認して新しい検証タブを使う。ブラウザー制御の別技術へ勝手に切り替えない。

`docs/design/food-guide/2026-10-14/`の2枚のプレビューは仕様初期版の参考画像。現在の1.5版とは異なり、公式ロゴ・文字バッジ・集合ピン・案内線の旧案が含まれる。実装用素材に流用しない。

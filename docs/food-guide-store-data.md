## 4. 旧ピクトグラムとアンカーの照合

### 4.1 方法

- 地図SVG（`src/assets/floors/ja/1F.svg`、`src/assets/floors/en/1F.svg`、どちらも `viewBox="0 0 1190.55 841.89"`）を単体でブラウザに開き、`getBBox` / `getCTM` で計測した。
- 黒い円（`#221815` / `#221f20`、直径5〜14、縦横差0.4未満）を候補にし、内側の白い図形の寸法で種類を判定した。複数の輪郭を含むパスはサブパスに分けて計測した。
- 店舗領域（検索データの `polygons`）の内側と、その外側0.012以内の円を照合し、各店舗を画像でも確認した。
- 正規化座標は `x / 1190.55`、`y / 841.89`。

- 日英差は最大0.27 SVG単位（正規化で約0.0002）。最大倍率10倍では約2.5pxになるため、言語別の値を使う。

### 4.3 除去時の注意

- 日英とも、食事・売店の旧ピクトグラムは上表の7個だけで、対象外の場所に同じピクトグラムはない。
- 除去するのは円と、その内側の白い図形だけ。LION・スターバックス・Meal Shop・Mini Meal Shop 等の引き出し線は残す。ピンの先端が引き出し線の起点に立つ。
- セブン-イレブンの売店ピクトグラムのすぐ右にATMのピクトグラム（日本語 (707.287, 472.469)、英語 (707.020, 472.393)）がある。施設リングで使うため残す。
- 日本語版の LION・スターバックスの白い図形は `<use>` 要素。
- 日本語版の Mini Meal Shop の円は、離れた位置（約 (262.2, 464.0)）にある引き出し線の点と同じ `<path>`（2つのサブパスの2つ目）。パスを分割し、円のサブパスだけを除く。英語版は単独のパス。
- 白い図形の分け方は日英で違う（例: 日本語版 Cafeteria はフォークとナイフが1パス、英語版は2パス）。要素番号ではなく位置と大きさで特定する。

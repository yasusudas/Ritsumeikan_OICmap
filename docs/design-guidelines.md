# デザインガイドライン

フラットなUI。公開ページはすべて「ゆるめのフラット」で、線で整えすぎず、余白と淡いグレーの塗りでまとめる。編集画面（`/editor/`）だけは作業ツールとして、1pxの罫線で区切る元のフラットデザインのまま。

| デザイン | 対象 | CSS |
| --- | --- | --- |
| ゆるめのフラット | 地図（`/`、`/en/`）、アクセス、時刻表（`/timetable/`、`/en/timetable/`）、OICフード、利用規約、プライバシーポリシー、旧URLのお知らせ（`public/legacy-moved.html`） | `loose.css` ＋ ページごとのCSS |
| 罫線のフラット | 編集画面（`/editor/`、`/editor/login/`） | `base.css` ＋ `editor.css` |

## 共通の原則（両方のデザイン）

- **影・ぼかし・グラデーションは使わない。** `box-shadow`、`backdrop-filter`、`linear-gradient`/`radial-gradient` は禁止（地図マーカーの白縁リングと、食事ピンの影だけ例外。食事ピンは食事案内仕様で認めたもの）。
- **文字の太さは3段階。** 本文400、UI・小見出し500、見出し700。800/900は使わない。強弱は主にサイズと色（`--c-ink` / `--c-ink-2` / `--c-ink-3`）でつける。
- **左揃えが基本。** 全ページで同じコンテナ幅（`--container` 1120px）と左端を使う。長文は1行40字前後（`--measure`）に収める。
- **見出しの型を統一。** 大きな見出し（`.page-title`）＋必要ならリード文（`.page-lead`）。見出しの上に小さな英字ラベル（以前の `.page-eyebrow`・`.section-eyebrow`、例: `ACCESS`・`LOCATION`）は付けない（2026-10-16 に全ページから削除）。
- **動きは控えめ。** 色の切り替え程度。浮き上がり（translateY）・拡大縮小・脈動アニメーションは使わない。例外は、開閉の状態を形で伝えるものだけ：地図の検索ピンが一度落ちてくる動き、メニューボタンの2本線が×になる動き、「その他」ボタンの点3つが上向きの山形（∧）につながる動き、「その他」パネルのボタンが上から順に6pxずれながら現れ下から順に消える動き、スマホの階選択リストと食事案内のカードが6pxずれながら現れ・消える動き、食事ピンのホバー時の小さな浮き上がり（どちらも拡大縮小はしない。速さは `viewer-loose.css` の `--ls-pop-dur` 120ms・`--ls-pop-step` 25ms で共通）。
- **フォーカスは必ず見える。** `outline: none` で消さない（`:focus-visible` は base.css で一括指定）。

## ゆるめのフラット（公開ページ）

`src/styles/loose.css` が `body[data-app-mode="viewer"]`（地図ページ）と `body.subpage`（その他の公開ページ）に効く。地図だけの部品（検索・フロア・施設ボタン）は `viewer-loose.css`。

- **線を使わない。** 区切り線・縁取りはなし。まとまりは余白、淡いグレーの塗り（`--ls-fill`、ホバーは `--ls-fill-2`）、文字の大きさで作る。鉄道会社の色の線や点は内容なので残す。
- **面は2種類の角丸。** まとまりはグレーの面（`--ls-sheet` 22px、大きな面は24〜28px）、その中の行は `--ls-row`（14px）。グレーの中にグレーを重ねない。グレーの面の中の操作部品は白。
- **ボタンはピル型。** グレーの塗り、枠線なし。主要な操作だけえんじの塗り。
- 文字入りピルは基本高さ36px・文字14px・左右余白16px（`--ls-pill-*`）。幅は内容に合わせ、長いラベルや文字拡大時は高さを伸ばす。絵文字・アイコンはサイズ調整のために追加しない。
- **色**：白と淡いグレーが基本。立命館のえんじ（`--ls-red`）は現在のページ・選択中の項目・主要ボタン・本文中のリンクだけ。強調したいバッジは淡いえんじ（`--ls-red-soft`）。時刻表の快速（A快速・新快速を含む）・準急ラベルは例外で、白地・1pxの同色枠・4px角丸（`--radius-control`）にする。快速は青 `#1112C6`（`--tt-rapid-blue`）、準急は緑 `#019C6C`（`--tt-semi-green`）を使う（2026-10-20 の指定画像から採色）。 他社サービスへの入口を示すボタンもブランドカラーを使う（時刻表の「LINEで予約」は `#06C755`）。
- **きっちり並べない。** セクションは見出しの下に本文を置き、罫線ではなく余白で区切る。地図ページは幅1240px以上でフロアを地図の左、施設を右に浮かべ、それより狭い幅とスマホでは一列にまとめる。選択中のフロアは小さな点で示す。
- **ヘッダー**：サイトアイコン（`public/icon/`）を角丸で切り抜き、大きめのサイト名と並べる。小さいスマホ（380px・340px以下）では文字を一段ずつ小さくして、サイト名を省略させない。
- **メニューボタン**：グレーの丸に、同じ太さ（2px）の平行な2本線。開くと×になる。メニューはグレーの面。
- **地図の拡大**：Chrome などPCのブラウザーは、拡大の1コマごとに地図を描き直し、常に鮮明に見せる。タッチ画面と Safari（Mac を含む WebKit）では毎コマの描き直しが重いため、拡大中は描いた地図を伸縮して見せ、倍率が変わる4コマに1回と、倍率が0.14秒止まったときに鮮明に描き直す（拡大中は最大2.5倍の引き伸ばしまでで、少しぼやける程度）。
- **施設アイコン**：線画（線幅1.6）を丸いボタンの中に28pxで置く。エレベーターと階段の人は、フロアマップのピクトグラムの形（頭は塗りの丸、体・腕・脚は細い線）をなぞる。編集画面は同じアイコンを `public/iconsvg/` から読み込み、48pxのボタンに28pxで置く。

## 罫線のフラット（編集画面）

- **カードを使わない。** 情報のまとまりは「上下の罫線（1px）」と「余白」で区切る。枠で囲んだ箱を積み重ねない。
- **角丸は2種類だけ。** レイアウト要素は `0`、操作部品は `var(--radius-control)`（4px）。ピル型は使わない。
- **アクセント（`--c-accent`）** は選択中の状態・リンク・主要ボタンだけ。

## トークン

`src/styles/tokens.css`（共通）と `src/styles/loose.css` の先頭（`--ls-*`）を参照。新しい色・サイズ・余白を直書きせず、必ずトークンを使う。

| 用途 | トークン |
| --- | --- |
| 背景 / 控えめな面 | `--c-bg` / `--c-bg-sub` |
| 文字（主・副・補助） | `--c-ink` / `--c-ink-2` / `--c-ink-3` |
| 罫線（編集画面） | `--rule`（`--c-line`）/ `--rule-strong`（`--c-ink`） |
| アクセント | `--c-accent` / `--c-accent-hover`（公開ページでは `--ls-red` に置き換わる） |
| ゆるめの面 | `--ls-fill` / `--ls-fill-2` / `--ls-sheet` / `--ls-row` |
| ゆるめのえんじ | `--ls-red` / `--ls-red-soft` |
| 文字サイズ | `--fs-2xs`〜`--fs-display` |
| 余白 | `--s-1`(4) 〜 `--s-9`(96) |

## 共通部品

- ヘッダー: `.site-header` > `.site-header-inner` > `.site-brand`（`.app-logo` + `.site-brand-name`。地図ページは `.app-title`）/ `.site-nav` / `.site-header-actions`（言語切替 `.lang-toggle`、メニュー `.site-menu`）
- ナビの項目と順番は全ページ共通: マップ / アクセス / 時刻表 / OICフード（＋メニュー内に「このサイトについて」「お問い合わせ」）。現在のページには `aria-current="page"`。
- ページ見出し: `.page-head` > `.page-title` + `.page-lead`
- セクション: `.section` > `.section-head`（`.section-title`）+ `.section-body`
- 長文: `.prose`
- 行のリスト: `.rule-list`（公開ページではグレーの角丸の行、編集画面では罫線の行）
- ボタン: `.btn`、`.btn-primary`（えんじ）、`.btn-quiet`、矢印 `.arrow` / 外部リンク `.external`
- ダイアログ: `.about-dialog-*`
- フッター: `.site-footer` > `.site-footer-inner` > `.site-footer-links` + `.site-footer-copy`
- 食事案内（地図のカード・一覧とOICフードで共通、`food-guide.css`）: 店舗内の小見出し `.food-heading`、状態や「臨時」のバッジ `.food-chip`（強調は `.is-accent` の淡いえんじ）、利用案内の2列表 `.food-usage-grid`、出典・生協カレンダーのリンク `.food-source-link`。地図カードのボタン `.food-control` と控えめな操作 `.food-text-control` は `.btn` と同じピル型。閉じるボタンは白い丸の ×

## CSSの構成

`src/style.css` は読み込み順だけを持ち、実体は `src/styles/` に分割している。旧URLのお知らせはViteを通らないので `public/legacy-moved.css` に単独で書く（トークンは同じ値をそろえる）。

| ファイル | 担当範囲 |
| --- | --- |
| `tokens.css` | デザイントークン |
| `base.css` | リセット・共通部品（罫線のフラット） |
| `viewer.css` | 地図ページ（`/`、`/en/`）と、編集画面と共有する地図レイヤー |
| `loose.css` | 公開ページ共通の「ゆるめ」のレイヤー（ヘッダー・メニュー・フッター・ダイアログ・セクション・ボタン） |
| `viewer-loose.css` | 地図ページだけの「ゆるめ」の部品（タイトル・検索・フロア・施設ボタン） |
| `timetable.css` | `/timetable/`、`/en/timetable/` |
| `pages.css` | `/access/`、`/food/`、`/terms/`、`/privacy/` |
| `editor.css` | `/editor/` の編集ツール |
